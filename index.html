교행e의 식단표 편집기자동 저장됨

사용 방법
  1. 기간에서 시작일을 고르면 날짜가 자동으로 채워져요.
  2. 표에 식단을 바로 입력하거나 엑셀로 입력을 이용하세요.
  3. 중복 표시에서 겹치는 음식을 확인하고 고치세요.
  4. 왼쪽 메뉴의 🖨 인쇄 / PDF 저장으로 출력하세요.

Ctrl+F: 음식 찾기 · 칸을 끌어서(또는 Shift+클릭) 여러 칸을 고른 뒤 Delete로 지우기, Ctrl+C / Ctrl+V로 복사·붙여넣기(엑셀 표도 그대로 붙여져요) · Ctrl+Z: 방금 한 작업 되돌리기

표 위의 시트 탭에서 + 새 시트로 다른 식단표를 만들고, 탭을 두 번 누르거나 ✎로 이름을 바꿔요.

입력한 내용은 이 브라우저에 자동 저장돼요. 다른 PC에서 이어 하려면 💾 작업 저장으로 받은 파일을 📂 작업 불러오기로 여세요. 엑셀 파일로 받으려면 ⬇ 식단표 엑셀 받기를 누르세요.

기간

고른 날짜가 있는 주의 월요일부터 채워져요. 표의 날짜를 누르면 하루씩 고칠 수 있어요.

칸 구성

칸 이름을 고치거나 간식 같은 새 칸을 추가해요. 위 보기에서 체크한 칸만 표에 나오고 인쇄돼요.

엑셀로 입력

서식을 받아 식단을 적고 저장한 뒤 올리면 표에 그대로 들어가요. 서식에는 지금 시작일과 제외 음식이 들어 있어요.

직접 만든 엑셀도 올릴 수 있어요. 월~토(또는 월~금)가 가로로 적힌 줄을 찾아 그 아래 음식을 채우고, 왼쪽 칸의 이름(조식·점심·간식 등)으로 칸을 나눠요. 한 칸에 여러 줄로 적은 메뉴도 줄마다 나눠 넣어요.

인쇄

용지와 줄 수를 고른 뒤 왼쪽 메뉴의 🖨 인쇄 / PDF 저장을 누르세요.

칸보다 긴 메뉴는 그 칸만 글씨가 저절로 작아져서 다 보이게 돼요.

목록은 학교 기준에 맞게 확인하고 고쳐 쓰세요.

음식 일괄 넣기

쌀밥·우유처럼 자주 나오는 음식을 고른 요일에 한 번에 넣거나 빼요.

중복 표시

겹치는 음식을 색으로 보여줘요. 체크를 끄면 색 없이 목록만 보여요.

같은 음식은 같은 색으로 칠해져요.
왼쪽 빨간 줄 = 같은 날 겹침
같은 날 겹침
같은 주 겹침
전체 기간에서 겹침

    중복 검사 제외 음식

    밥·김치처럼 매일 나오는 음식은 여기 적으면 검사에서 빠져요. 띄어쓰기와 알레르기 번호(예: 5.6.13)는 무시하고 비교해요.

    공휴일 직접 추가

    법정 공휴일·대체공휴일(2025~2028)은 이미 빨간색으로 표시돼요. 개교기념일·재량휴업일 등은 한 줄에 하나씩 날짜 이름으로 적으세요.
